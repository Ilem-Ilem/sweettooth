✅ FEATURE OVERVIEW
───────────────────────────────────────────────────────────────────────────────
Automatically synchronizes recipe yield quantities across product and recipe
creation forms. Users enter batch weight and unit weight, system calculates
the number of units produced: Recipe Yield = Batch Weight ÷ Unit Weight

✅ FEATURES IMPLEMENTED
───────────────────────────────────────────────────────────────────────────────

1. Real-Time Auto-Calculation
   • As users type weights, yield updates instantly
   • Uses Livewire computed properties
   • Formula: Yield = Batch Weight ÷ Unit Weight

2. Product-to-Recipe Synchronization
   • Select product in recipe form
   • All yield-related fields auto-populate
   • Prevents data entry errors

3. Smart Validation (3 Rules)
   • Rule 1: If both weights provided, yield must match calculation (±0.01)
   • Rule 2: Weights must come in pairs (both or neither)
   • Rule 3: Manual yield allowed without weights

4. User-Friendly Interface

   • Validation errors with expected values

   • Computed properties ensure consistency
   • Backward compatible with existing data

1. Enter batch weight (e.g., 1200g)
2. Enter unit weight (e.g., 100g)
3. System auto-calculates yield: 12 units
4. Click Save (validation checks consistency)

Creating a Recipe:
1. Select a product → all yield fields auto-populate
2. Optionally modify weights → yield auto-updates
3. Add ingredients → save with validated consistency
