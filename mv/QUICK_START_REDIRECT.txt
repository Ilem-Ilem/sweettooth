KEY IMPLEMENTATION DETAILS
================================================================================

CLOCK-IN CHECK:
  DashboardRedirectController::hasClockInToday()
  - Checks if employee has active shift for today
  - Status must be 'active'
  - Shift date must be today
  - If no shift → redirect to clock-in page
  - If shift exists → proceed to dashboard

SESSION FLUSH:
  Logout::__invoke()
  - Auth::guard('web')->logout()        (super admin)
  - Auth::guard('employees')->logout()  (staff)
  - Session::flush()                    (destroy all)
  - Session::regenerateToken()          (new CSRF)

SUPPORT NOTES
================================================================================

If staff is redirected to clock-in page:
  → Normal behavior if no active shift exists for today
  → Check: Shift::where('employee_id', $id)
                ->where('shift_date', Carbon::today())
                ->where('status', 'active')
                ->exists()

If super admin cannot access dashboard:
  → Check if user has roles assigned
  → Verify role name matches getDashboardRoute() mapping
  → Check is_super_admin() returns true (web guard, not employees)

If session not clearing on logout:
  → Clear browser cache and cookies
  → Verify Session::flush() is called
  → Check logs for errors

If wrong dashboard is shown:
  → Check user's roles: $user->roles()->pluck('name')
  → Verify highest priority role in getHighestPriorityRole()
  → Check role mapping in getDashboardRoute()
