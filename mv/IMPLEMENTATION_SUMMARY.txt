HOW TO ACCESS & USE
================================================================================

1. DASHBOARD
   URL: http://localhost/branch-dashboard/accounting/dashboard
   Purpose: View financial summaries, recent entries, period info
   Features: Period selector, KPI cards, recent entries table

2. GL ACCOUNTS
   URL: http://localhost/branch-dashboard/accounting/accounts
   Purpose: View and manage chart of accounts
   Features: Search, filter, sort, activate/deactivate

3. JOURNAL ENTRIES
   URL: http://localhost/branch-dashboard/accounting/journal-entry
   Purpose: Create manual journal entries
   Features: Dynamic line items, balance validation, draft/post options

4. ACCOUNTING PERIODS
   URL: http://localhost/branch-dashboard/accounting/periods
   Purpose: Manage accounting periods
   Features: Create, close, reopen, lock periods

5. BANK RECONCILIATION
   URL: http://localhost/branch-dashboard/accounting/bank-reconciliation
   Purpose: Reconcile bank accounts
   Features: Match transactions, mark as reconciled

6. FINANCIAL REPORTS
   URLs: /branch-dashboard/accounting/reports/*
   Purpose: Generate financial statements
   Features: Trial Balance, Balance Sheet, Income Statement, etc.

SUPPORT & TROUBLESHOOTING
================================================================================

Dashboard Won't Load:
  php artisan route:clear
  php artisan view:clear
  php artisan cache:clear

GL Accounts Missing:
  php artisan db:seed --class=GlAccountSeeder

Periods Not Showing:
  php artisan db:seed --class=AccountingPeriodSeeder

Component Errors:
  php artisan livewire:discover

Database Issues:
  php artisan migrate:refresh
  php artisan migrate
  php artisan db:seed
