# Store Keeper Role Documentation

## Overview
The **Store Keeper** role manages warehouse operations, stock storage, and basic inventory handling.

## Access Level
- **Warehouse Operations**: Basic stock handling and storage
- **Inventory Access**: Stock receiving and transfers
- **Limited Control**: Essential warehouse functions

## Key Responsibilities
- Stock receiving and storage
- Inventory transfers
- Warehouse organization
- Basic inventory monitoring

## Permissions
- view-stock-levels, receive-stock, transfer-stock
- view-inventory-reports

## Notes
- Warehouse operations focus
- Physical stock handling
- Basic inventory management
- Storage and organization

## Security Considerations
- Physical inventory security
- Stock handling procedures
- Warehouse access control
