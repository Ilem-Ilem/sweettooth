# Kitchen Staff Role Documentation

## Overview
The **Kitchen Staff** role handles day-to-day production execution in the kitchen environment.

## Access Level
- **Production Execution**: Basic production operations
- **Recipe Access**: View production recipes
- **Queue Management**: Production queue monitoring

## Key Responsibilities
- Production order execution
- Recipe following
- Production queue monitoring
- Basic quality checks

## Permissions
- view-production-queue, start-production, complete-production
- view-recipes

## Notes
- Entry-level production role
- Production execution focus
- Limited authority
- Quality awareness required

## Security Considerations
- Production process compliance
- Recipe access control
- Basic quality standards
