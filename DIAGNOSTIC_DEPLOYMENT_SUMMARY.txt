⚡ STEP-BY-STEP USAGE
═══════════════════════════════════════════════════════════════════════════

Step 1: Hard Refresh Browser
        Ctrl+Shift+R (Windows/Linux) or Cmd+Shift+R (Mac)

Step 2: Navigate to Diagnostic
        http://localhost/README.html

Step 3: Click "Run Full Diagnostics"
        Takes to: http://localhost/diagnose.html

Step 4: Click "Run Full Diagnostic" Button
        Analyzes all systems (completes in 2-5 seconds)

Step 5: Review Results in 5 Tabs
        • Environment - Check Alpine & Livewire
        • Components - See component counts
        • Loading States - Verify no stuck loaders
        • Network - Check asset loading
        • Console - Review diagnostic output

Step 6: Test Your Application
        Click "Open App" to test in new window
        Watch loading states during interactions

Step 7: Export Results (Optional)
        Click "Export Report" to save JSON file

🔧 TROUBLESHOOTING GUIDE
═══════════════════════════════════════════════════════════════════════════

Problem: Stuck loaders detected
└─ Solution: 
   1. Check F12 → Network for failed requests
   2. Hard refresh: Ctrl+Shift+R
   3. Run php artisan cache:clear

Problem: Alpine.js missing
└─ Solution:
   1. Hard refresh: Ctrl+Shift+R
   2. Run npm run build
   3. Restart server

Problem: Can't access diagnostic
└─ Solution:
   1. Make sure server is running
   2. Try http://127.0.0.1/README.html
   3. Check firewall/localhost setup
