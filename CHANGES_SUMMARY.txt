================================================================================
VALIDATION FLOW
================================================================================

Employee Creation:
  1. Form Loads
  2. User Selects Department (Required)
  3. User Selects Role(s) (Optional)
  4. User Clicks Save
  5. Validation Checks:
     - Is user super admin? → Skip remaining checks
     - Does user have department? → Required
     - Is each role valid for department? → Check mapping
  6. If All Valid → Create + Log + Show Success
  7. If Invalid → Show Error + Prevent Save

Employee Edit:
  Same as Creation, but updates existing employee

================================================================================
ERROR MESSAGES
================================================================================

"User must be assigned to a department before assigning roles"
  → Select a department first

"The 'Chef' role is only available for Kitchen department staff.
  Please choose a different role for this employee."
  → Choose compatible role or change department

"User department not found"
  → Database integrity issue, contact admin

DATABASE CHANGES
================================================================================

BEFORE:
  ALTER TABLE users CHANGE COLUMN department_id VARCHAR(36) NULLABLE

AFTER:
  ALTER TABLE users CHANGE COLUMN department_id VARCHAR(36) NOT NULL
  CREATE INDEX idx_users_department_id ON users(department_id)

REVERSIBLE:
  php artisan migrate:rollback

================================================================================
AUDIT TRAIL
================================================================================

All role assignments are logged with:
  - User making the change
  - Employee being changed
  - Old roles → New roles
  - Timestamp
  - Reason (creation vs edit)

Access in code:
  $employee->auditLogs()->where('type', 'role_change')->get()

================================================================================
SUPER ADMIN EXEMPTION
================================================================================

Users with roles: Super Admin, MD, or Managing Director are:
  ✓ Exempt from department requirement
  ✓ Can assign any role without validation
  ✓ Can access all departments
  ✓ Can skip department selection

Regular users are:
  ✗ Must have department
  ✗ Roles validated against department
  ✗ Department selection required
