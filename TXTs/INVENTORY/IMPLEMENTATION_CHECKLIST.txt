Quick Reference: How to Implement
For Any Component Needing Approval:
Step 1: Add Component Properties
php
public $showAuditModal = false;
public $auditReason = '';
public $auditAction = null;
public array $pendingActionData = [];
Step 2: Add Conditional Save Logic
php
public function save() {
    $this->validate($this->rules);
    
    if (issuperadmin()) {
        $this->executeImmediate();
        return;
    }
    
    // Non-admin: Store and show audit modal
    $this->pendingActionData = [/ data /];
    $this->auditAction = 'actionname';
    $this->showAuditModal = true;
}
Step 3: Add Audit Modal Handler
php
public function submitAuditRequest() {
    $this->validate(['auditReason' => 'required|min:10']);
    
    InventoryApprovalService::request[Action](
        Auth::guard('employees')->user(),
        $this->pendingActionData,
        $this->auditReason
    );
    
    $this->closeAuditModal();
}

Common Issues & Solutions
Issue: "Undefined array key" errors
Solution: Add null coalescing in service
php
$value = $payload['field'] ?? 0;  // Before using
Issue: Modal not closing after approval
Solution: Call closeAuditModal() in submit handler
php
$this->closeAuditModal();
Issue: Data lost during form reset
Solution: Don't reset pendingData until approval completes
php
// Bad: $this->reset(['pendingData', ...]);
// Good: Only reset after successful audit submission
Issue: Reorder/max levels not updating
Solution: Ensure service updates item in transaction
php
$stock->item->update(['reorderlevel' => ...]);
