Field Mapping Summary
Correct StockMovement Fields
php
[
    'stockid'       => int,                          // ✓ Required
    'type'           => 'in|out|adjustment|...',     // ✓ Required
    'quantity'       => float,                        // ✓ Required
    'quantitybefore' => float,                       // ✓ Required - For audit
    'quantityafter'  => float,                       // ✓ Required - For audit
    'referencetype' => 'App\Models\Purchase' or null, // ✓ Valid model or null
    'referenceid'   => int or null,                  // ✓ Only if referencetype set
    'movedbytype'  => 'App\Models\Employee' etc,    // ✓ Required - Who did it
    'movedbyid'    => int,                          // ✓ Required - ID of actor
    'movementdate'  => Carbon datetime,              // ✓ Required - When
    'notes'          => string,                       // ✓ Description
]
Incorrect Fields (Removed)
✗ itemid - Use stock → item relationship
✗ branchid - Use stock → branch relationship
✗ movementtype - Use type
✗ recordedby - Use movedbytype + movedbyid
✗ movedby - Use movedbytype + movedbyid
✗ referencetype: 'manualadjustment' - Invalid string, use null
✗ referencetype: 'approvaladjustment' - Invalid string, use null
