Stock Movement Integration - Complete Implementation
Summary
Implemented comprehensive stock movement tracking for all inventory operations:
✓ Purchases (incoming stock with reference to Purchase model)
✓ Manual adjustments (no external reference, tracked by actor)
✓ Outgoing stock (future: dispatches, transfers, damaged, etc.)
Data Structure
Stock Movement Schema
Every movement records:
php
[
    'stockid'       => $stock->id,              // Which stock changed
    'type'           => 'in|out|adjustment',     // Movement type
    'quantity'       => 10.5,                    // Amount moved
    'quantitybefore' => 100.0,                  // Stock before
    'quantityafter'  => 110.5,                  // Stock after
    'referencetype' => 'App\Models\Purchase',   // What triggered it (can be null)
    'referenceid'   => $purchase->id,           // ID of triggering entity
    'movedbytype'  => 'App\Models\Employee',   // Who performed it
    'movedbyid'    => $employee->id,           // ID of actor
    'movementdate'  => Carbon::now(),           // When it happened
    'notes'          => 'Purchase: PUR-...',     // Description
]

Purchase Model Relationship
File: app/Models/Purchase.php
Added relationship to track stock movements created from this purchase:
php
public function stockMovements(): HasMany
{
    return $this->hasMany(StockMovement::class, 'referenceid')
        ->where('referencetype', 'App\Models\Purchase');
}
Allows:
php
$purchase->stockMovements()->get();  // Get all stock movements from this purchase
$purchase->stockMovements()->sum('quantity');  // Total quantity added
