Common Issues & Solutions
Issue: Charts don't update when filter changes
Solution: 
Check browser console for JavaScript errors
Verify Livewire is initialized
Check that livewire:updated event fires
Reload page and try again
Issue: Charts load but show wrong data
Solution:
Verify filter values in browser DevTools
Check that data methods are called with filters
Ensure database has movement records for selected filters
Issue: Charts are slow to update
Solution:
Check database query performance
Verify indexes are in place (see DATABASEOPTIMIZATION.md)
Reduce date range to improve performance
Check browser DevTools performance tab
Issue: Charts don't show up at all
Solution:
Check that Highcharts CDN is loaded (Network tab)
Verify chart div IDs exist in DOM
Check browser console for Highcharts errors
Try hard refresh (Ctrl+Shift+R)
Issue: Charts appear but styled incorrectly
Solution:
Clear browser cache
Hard refresh page
Verify dark mode CSS loads
Check browser zoom level (try 100%)

Rollback Instructions
If issues found, rollback is simple:
Revert component changes:
   bash
   git checkout app/Livewire/BranchDashboard/Analytics/StockMovementAnalytics.php
   
Revert blade changes:
   bash
   git checkout resources/views/livewire/branch-dashboard/analytics/stock-movement-analytics.blade.php
   
Clear cache:
   bash
   php artisan cache:clear
   php artisan view:clear
   
Refresh browser: Ctrl+Shift+R
No database changes were made, so no migrations to rollback.
