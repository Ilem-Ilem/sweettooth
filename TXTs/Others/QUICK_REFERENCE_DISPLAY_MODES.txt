Bars: Relative value visualization
Accordion: Grouped by category

List: Default sort order

Pagination

---
How to Switch Views
Locate the View Mode Tabs below the filters
Click on desired view:
   - 📋 Table
   - 🎴 Cards
   - 📝 List
   - 📊 Visual Bars
   - 📂 By Category
View automatically switches and pagination resets
---
Filters Work on All Views
Search - Searches item name & SKU across all views
Category Filter - Filters by category across all views
Changes apply immediately to current view

Summary Cards (Always Visible)

Reserved - Value of reserved stock
Damaged - Value of damaged stock
Total Items - Number of SKUs

Top Analysis Sections (Always Visible)
Below summary cards:
Valuation by Category Table - Category breakdown
