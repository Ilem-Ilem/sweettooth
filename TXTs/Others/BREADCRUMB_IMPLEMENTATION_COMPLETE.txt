Breadcrumb Template Pattern
All pages follow the same pattern:
blade
<x-breadcrumb
    title="Page Title"
    :items="[
        ['label' => 'Dashboard', 'url' => branchroute('branch-dashboard.index')],
        ['label' => 'Inventory'],
        ['label' => 'Current Page']
    ]"
    :compact="false"
    :with-icons="true"
/>
For Report Pages (with nested structure):
blade
<x-breadcrumb
    title="Report Name"
    :items="[
        ['label' => 'Dashboard', 'url' => branchroute('branch-dashboard.index')],
        ['label' => 'Inventory'],
        ['label' => 'Reports'],
        ['label' => 'Specific Report']
    ]"
    :compact="false"
    :with-icons="true"
/>
