Quick Reference - Item Deletion Feature
Current Behavior
When an item is deleted:
| What | Happens | Why |
|------|---------|-----|
| Item | ❌ DELETED | User requested deletion |
| RecipeIngredient | ❌ DELETED | Item removed from recipes |
| Recipe | ⚠️ INCOMPLETE | Missing ingredient marked in logs |
| Product | ✅ STAYS ACTIVE | Can't be produced but stays in system |
| Stock | ❌ DELETED | Cascaded via foreign key |
| StockMovement | ❌ DELETED | Cascaded via foreign key |
| PurchaseItem | ❌ DELETED | Item removed from purchases |
| Audit Logs | 📝 CREATED | 4-5 entries documenting everything |

Key Code Points
Finding Related Data
php
// Find recipes using item
$recipeIngredients = RecipeIngredient::where('itemid', $item->id)
    ->with('recipe.product')
    ->get();
// Get affected products
$products = $recipeIngredients->map(fn($ri) => $ri->recipe->product)
    ->unique('id');
Executing Deletion
php
// Step 1: Get affected recipes
$affectedRecipeIds = RecipeIngredient::where('itemid', $itemId)
    ->pluck('recipeid')
    ->toArray();
// Step 2: Delete recipe ingredients
RecipeIngredient::where('itemid', $itemId)->delete();
// Step 3: Check recipe integrity
foreach ($affectedRecipeIds as $recipeId) {
    $recipe = Recipe::find($recipeId);
    if ($recipe->ingredients()->count() === 0) {
        // Log incomplete recipe
    }
}
// Step 4: Delete item (cascades to stocks, purchases, etc)
$item->delete();
// Step 5: Create audit logs
AuditService::log(/ details /);

Common Questions
Q: Can I delete an item in use?
A: Yes, but admin must approve. Related data is shown first.
Q: What if a recipe loses all ingredients?
A: Recipe stays but is marked incomplete in audit logs. Admin must fix it.
Q: Can I undo a deletion?
A: Currently no. Recovery requires recreating recipes/stock from backups.
Q: Are products deleted too?
A: No. Products stay active but can't be produced.
Q: How long does deletion take?
A: Depends on data volume. Usually <1 second for typical items.
Q: What if deletion fails?
A: Transaction rolls back. All changes reverted. Request stays pending.
