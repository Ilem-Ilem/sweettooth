Purchase & Stock Movement Integration - Complete Fix
Problem
Stock movement analytics page had no data for purchases. Stock movements were not being created when purchases were approved.
Root Causes
PurchaseAuditApprovalService - Missing stock movement creation when purchases are approved
executePurchaseCreation() - Didn't create stock movements for newly created purchases
approvePurchase() - Didn't create stock movements when approving draft purchases
Solution Implemented
Updated PurchaseAuditApprovalService 
File: app/Services/PurchaseAuditApprovalService.php
Added Imports
php
use App\Models\Stock;
use App\Models\StockMovement;
Updated approvePurchase() Method
When a draft purchase is approved:
Loads purchase items with the purchase
For each item:
  - Creates/finds the stock record
  - Updates average cost using weighted average
  - Records quantity before update
  - Increases stock quantity
  - Creates StockMovement record with:
    - type: 'in' (incoming stock)
    - quantitybefore / quantityafter (tracks change)
    - referencetype: 'App\Models\Purchase' (links to purchase)
    - referenceid: $purchase->id (links to specific purchase)
    - movedbytype / movedbyid (tracks who approved)
    - movementdate: $purchase->purchasedate
Updated executePurchaseCreation() Method  
When a new purchase is created via approval:
Creates purchase with proper fields including recordedbyid and recordedbytype
For each purchase item:
  - Creates purchase item record
  - Creates/finds stock record
  - Updates average cost
  - Creates StockMovement record immediately after stock update
  - Logs completion with item count and costs

Stock Movement Analytics shows purchase data ✓
StockMovement Fields
Every purchase now creates StockMovement with:
| Field | Value |
|-------|-------|
| stockid | ID of stock record being updated |
| type | 'in' (purchase incoming stock) |
| quantity | Amount added from purchase |
| quantitybefore | Stock level before purchase |
| quantityafter | Stock level after purchase |
| referencetype | 'App\Models\Purchase' (full class name) |
| referenceid | Purchase ID |
| movedbytype | Class of who approved (Employee/User) |
| movedbyid | ID of approver |
| movementdate | Purchase date |
| notes | 'Purchase: [purchasenumber]' |
