How It Works
Filter Change Flow
User changes filter (date, item, type, shift, dept, search)
   ↓
Livewire's updated() hook fires
   ↓
Filter is validated (date range check)
   ↓
chartsNeedUpdate event dispatched
   ↓
JavaScript listener catches event
   ↓
updateCharts() function called
   ↓
Fresh chart data fetched from blade template (@js variables)
   ↓
Previous chart instances destroyed
   ↓
New charts rendered with latest data
   ↓
Charts display updated immediately
Real-Time Update Mechanism
javascript
// Three ways charts get updated:
Livewire event: Livewire.on('chartsNeedUpdate')
Page update: document.addEventListener('livewire:updated')
Page load: document.addEventListener('livewire:initialized')
