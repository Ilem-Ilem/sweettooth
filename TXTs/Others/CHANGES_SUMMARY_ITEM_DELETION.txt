Recipes & Recipe Ingredients: What Happens?
Current Behavior (Option 1 - Simpler)
When you delete an item:
RecipeIngredients are deleted - Removes the item from all recipes
Recipes survive but become incomplete (missing ingredient)
Audit log created - Admin sees which recipes became incomplete
Products unaffected - Stay in system, can use other recipes
Example:
Deleting: Flour (used in 2 recipes)
Result:
✅ Item deleted
✅ Recipe "Bread" now incomplete (missing Flour)
✅ Recipe "Cake" now incomplete (missing Flour)
✅ Product "Bread" stays active but can't be produced
✅ Audit log created for review
Pros:
Simple, clean implementation
No database migration
Clear when recipes are broken
Easy to fix (recreate recipe with new item)
Cons:
Historical recipe data lost
Recipe details become incomplete
---
Alternative Behavior (Option 2 - Advanced)
If you prefer to preserve recipes with deleted items:
Make itemid nullable in recipeingredients table (migration)
Item gets deleted but RecipeIngredient records stay with itemid = NULL
Recipes survive but show "Item Deleted" in UI
Admin can reassign new item to the recipe
Example:
Deleting: Flour (used in 2 recipes)
Result:
✅ Item deleted
✅ Recipe "Bread" stays with "❌ Item Deleted" showing
✅ Recipe "Cake" stays with "❌ Item Deleted" showing
✅ Product "Bread" stays active but can't be produced
✅ Admin can fix by setting new item
Pros:
Recipes fully preserved
Historical data intact
Can reassign items
Better for historical tracking
Cons:
Requires 1 database migration
More complex code changes
Need UI updates to show deleted items
---
Which Should You Use?
Choose Option 1 (Current) if:
You want the simplest approach
It's okay to recreate recipes after item deletion
You want to force cleanup
You don't need historical recipe details
Choose Option 2 if:
You need historical recipe preservation
You want flexibility to reassign items
You have complex production history to maintain
You're willing to do a small migration
---
How to Implement Option 2
If you want to switch to Option 2 later:
See the complete guide in: PRESERVERECIPESONITEMDELETE.md
Quick steps:
bash
Create migration
php artisan make:migration makeitemidnullableinrecipeingredientstable
Run migration (copy code from the guide)
php artisan migrate
Update deletion logic in InventoryApprovalService
Change: RecipeIngredient::where('itemid', $itemId)->delete()
To: RecipeIngredient::where('itemid', $itemId)->update(['itemid' => null])
Update views to show deleted items
Add conditional rendering for null items
