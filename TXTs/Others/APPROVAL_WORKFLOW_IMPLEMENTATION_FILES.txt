📋 QUICK START
================================================================================

1. ADD TRAIT TO COMPONENT (1 minute)
   use App\Traits\RequiresApprovalWorkflow;

2. UPDATE SAVE METHOD (5 minutes)
   if ($this->isSuperAdmin()) {
       $this->executeCreate();
   } else {
       $this->showReasonModal = true;
   }

3. ADD REASON MODAL (5 minutes)
   @if($showReasonModal)
   <div class="modal">
       <textarea wire:model="reason"></textarea>
       <button wire:click="submitRequest">Submit</button>
   </div>
   @endif

4. SUBMIT FOR APPROVAL (1 minute)
   $this->submitForApproval(
       'create',
       'item',
       null,
       ['name' => $this->name, ...],
       $this->reason
   );

Total: ~25 minutes per component
