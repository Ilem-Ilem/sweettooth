PRIORITY 4: ADD MISSING MODEL CONVENIENCE METHODS (MEDIUM SEVERITY)
===================================================================

Time: 1 hour
Severity: MEDIUM
Blocks: Better API design

In ProductDispatchCallback.php, add after line 238:

    /**
     * Mark callback as approved and received (convenience method)
     */
    public function approveAndReceive($actor = null): bool
    {
        if (!$this->approve($actor)) {
            return false;
        }

        return $this->markAsReceived($actor);
    }

    /**
     * Mark callback as approved, received, and completed (full workflow)
     */
    public function approveReceiveAndComplete($actor = null): bool
    {
        if (!$this->approve($actor)) {
            return false;
        }

        if (!$this->markAsReceived($actor)) {
            return false;
        }

        return $this->completeWithStockUpdate();
    }

In ApproveCallbacks.php getFilteredQuery() (line 62-71):

    {
        $query = ProductDispatchCallback::query()
            ->with([...])
            ->whereHas('productDispatch.salesShift', function ($q) {
                $q->where('branch_id', $this->getBranchId());
            });
        return $query;
    }

TO:
    protected function getFilteredQuery()
    {
        $branchId = $this->getBranchId();
        
        $query = ProductDispatchCallback::query()
            ->with([...])
            ->where(function ($q) use ($branchId) {
                // Filter by salesShift branch directly
                $q->whereHas('salesShift', function ($sq) {
                    $sq->where('branch_id', $branchId);
                })
                // Also handle case where productDispatch is NULL
                ->orWhereHas('productDispatch.salesShift', function ($sq) {
                    $sq->where('branch_id', $branchId);
                });
            });

        return $query;
    }

This ensures callbacks are found even if productDispatch is NULL.
