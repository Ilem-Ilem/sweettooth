STEP 1: Add AuditService Import
   Add to component class:
   ```php
   use App\Services\AuditService;
   ```

STEP 2: Log Create Operations
   In your create/save method:
   ```php
   AuditService::log(
       auth('employees')->user() ?? auth()->user(),
       'create_resource_name',
       $model,
       'Human-readable description of what was created',
       'completed'
   );
   ```

STEP 3: Log Update Operations
   In your update method:
   ```php
   AuditService::log(
       auth('employees')->user() ?? auth()->user(),
       'update_resource_name',
       $model,
       'Description of what changed and why',
       'completed'
   );
   ```

STEP 4: Log Delete Operations
   In your delete method:
   ```php
   AuditService::log(
       auth('employees')->user() ?? auth()->user(),
       'delete_resource_name',
       $model,
       'Reason for deletion',
       'completed'
   );
   ```

STEP 5: Log Sensitive Operations (with approval)
   For approval-required operations:
   ```php
   $result = AuditService::logSensitiveAction(
       auth('employees')->user() ?? auth()->user(),
       'sensitive_action_name',
       $model,
       'Reason from user input',
       ['context' => 'additional context']
   );
   
   if ($result['status'] === 'pending') {
       $this->toast()->warning('Action requires approval')->send();
   }
   ```

STEP 6: Add Audit Modal for Sensitive Actions (if needed)
   Include blade template:
   ```blade
   @include('livewire.branch-dashboard.inventory.partials.audit-modal', [
       'showModal' => $this->showAuditModal,
       'auditReason' => $this->auditReason,
   ])
   ```

STEP 7: Test Audit Logging
   - Check AuditManagement > Index for logs
   - Verify causer, action, timestamp recorded
   - Verify old_values and new_values captured
   - Verify status is correct

SECTION 7: QUICK IMPLEMENTATION GUIDE
==========================================================

MINIMUM AUDIT IMPLEMENTATION (15 mins per component):

For any component, add these 3 methods to capture core audit:

1. Log Create:
```php
private function logCreate($model, $description)
{
    AuditService::log(
        current_actor(),
        'create_' . class_basename($model),
        $model,
        $description
    );
}
```

2. Log Update:
```php
private function logUpdate($model, $description)
{
    AuditService::log(
        current_actor(),
        'update_' . class_basename($model),
        $model,
        $description
    );
}
```

3. Log Delete:
```php
private function logDelete($model, $description)
{
    AuditService::log(
        current_actor(),
        'delete_' . class_basename($model),
        $model,
        $description
    );
}
```

Then call these in your Livewire methods.


ENHANCED AUDIT WITH APPROVAL (30 mins per component):

1. Add audit modal blade to your view
2. Add properties to component:
   ```php
   public bool $showAuditModal = false;
   public ?string $auditReason = null;
   public ?string $auditAction = null;
   ```

3. Show modal before sensitive operations:
   ```php
   public function initiateDelete($id)
   {
       $this->selectedId = $id;
       $this->auditAction = 'delete';
       $this->auditReason = '';
       $this->showAuditModal = true;
   }
   ```

4. Process with audit after modal confirmation:
   ```php
   public function submitAuditedAction()
   {
       if ($this->auditAction === 'delete') {
           $model = Model::find($this->selectedId);
           AuditService::log(
               current_actor(),
               'delete_resource',
               $model,
               $this->auditReason
           );
           $model->delete();
       }
   }
   ```

SECTION 10: AUDIT SYSTEM REFERENCE
==========================================================

MAIN AUDIT SERVICE METHODS:

1. Basic Logging:
   AuditService::log($causer, $action, $auditable, $description)

2. Sensitive Action Logging:
   AuditService::logSensitiveAction($causer, $action, $auditable, $reason)

3. Actor Reference Updates:
   AuditService::updateActorReference($target, $relationshipName, $actor)

4. Relationship Sync Logging:
   AuditService::logSync($causer, $auditable, $relationship, $syncData)

5. Retrieve Audit Logs:
   AuditService::getLogsFor($model)
   AuditService::getLogsByActor($user)
   AuditService::getPendingApprovals()

HELPER FUNCTION:
   current_actor() - Returns authenticated user (User or Employee)


APPROVAL MODELS:
   - ApprovalRequest (deprecated, legacy)
   - ApprovalAuditRequest (new standard for audit approvals)
   - PurchaseApprovalRequest (purchase-specific)


AUDIT LOG STATUSES:
   - 'pending' - Awaiting approval
   - 'completed' - Action executed successfully
   - 'rejected' - Approval was rejected
   - 'approved' - Approval was granted
