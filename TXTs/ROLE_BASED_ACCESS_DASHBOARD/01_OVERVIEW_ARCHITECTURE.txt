1. PROJECT OBJECTIVES
===============================================================================

This implementation will deliver a complete Role-Based Access Control (RBAC) system
integrated with module-specific dashboards across 6 main modules:

Modules to implement:
  ✓ Inventory Module
  ✓ Production Module
  ✓ HR Module
  ✓ Sales Module
  ✓ Admin Dashboard (Branch level)
  ✓ Super Admin Dashboard (Global level)

Key Features:
  • Each role lands on their appropriate dashboard
  • Branch managers can access all departments within their branch
  • Super admin can access all departments across all branches
  • Existing branch switching functionality preserved
  • Hierarchical role permissions system

4. ROLE HIERARCHY & MODULE ACCESS
===============================================================================

MODULE ACCESS BY ROLE HIERARCHY:

Level 5 (Executive) - Super Admin / Managing Director
  └─ Access: ALL modules, ALL branches, ALL departments
  └─ Dashboard: Executive Dashboard (KPIs, all branch analytics)

Level 4 (Management) - Admin / Head of Production / Sales Manager / HR Manager / Inventory Manager
  └─ Access: Relevant modules, own branch, all departments in branch
  └─ Dashboard: Department/Module Management Dashboard
  
Level 3 (Supervisor) - Chef, Head of Gelato, Confectionaries Manager, Till Supervisor
  └─ Access: Own department production/sales, limited reports
  └─ Dashboard: Department Operation Dashboard
  
Level 2 (Officer) - HR Officer, Stock Controller, Store Keeper
  └─ Access: Own function area, view permissions only for other areas
  └─ Dashboard: Function-Specific Dashboard
  
Level 1 (Staff) - Kitchen Staff, Cashier, Store Staff, Production Staff
  └─ Access: Own tasks and immediate area
  └─ Dashboard: Simple Task Dashboard
